# 试卷导入目录

两种收录方式，任选其一。

## 方式一：网页上传（推荐）

打开网站「试卷」→ 选择等级 → 点某个年份的「上半年 / 下半年」（考研为「英语（一）/（二）」）→
在弹窗里把文件拖进去，或点「选择文件」。一套试卷可以传多个文件（试卷、答题卡、听力音频等）。

## 方式二：放到本目录，运行命令

```bash
npm run import:papers
```

或指定其他目录：

```bash
npm run import:papers -- --dir "D:\我的试卷"
```

## 命名规范

`{等级}_{年份}_{场次}.{扩展名}`

| 等级 | 场次 | 示例 |
|---|---|---|
| `CET4` 四级 | `H1` 上半年 / `H2` 下半年 | `CET4_2024_H1.pdf` |
| `CET6` 六级 | `H1` 上半年 / `H2` 下半年 | `CET6_2023_H2.md` |
| `KY` 考研英语 | `A` 英语（一） / `B` 英语（二） | `KY_2022_A.pdf` |

支持的扩展名：`pdf`、`docx`、`md`、`txt`、`json`、`png`、`jpg`、`jpeg`、`webp`、`gif`、
`mp3`、`m4a`、`wav`。

同一场次的不同类型文件（例如试卷 `CET4_2024_H1.pdf` + 听力 `CET4_2024_H1.mp3`）会自动合并到同一份试卷下。
同一种扩展名的多页扫描图（多张 JPG）请用网页上传，命令行目录里同名文件无法共存。

## 导入结果

- 原文件整份复制到 `server/data/papers/`
- 网站「试卷」页面对应年份/场次标记为「已收录」
- `md` / `txt` / `json` 还会把全文写入数据库 `papers.content`
- 点击文件列表中的文件名即可在浏览器里打开；PDF、图片、音频可直接预览
