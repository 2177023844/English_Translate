# 果冻学英语 — 固定域名隧道配置指南

让网站有一个**永久不变的公网地址**（如 `https://english.你的域名.com`），隧道掉线自动重连，无需每次记新地址。

## 前置准备（一次性，约 15 分钟）

### 1. 注册 Cloudflare 免费账号
打开 https://dash.cloudflare.com/sign-up ，用邮箱注册（免费，无需绑卡）。

### 2. 准备一个域名并托管到 Cloudflare
- **没有域名**：在阿里云/腾讯云买一个（.com 约 ¥60/年，.xyz/.top 等更便宜），或 Cloudflare 域名注册服务
- 登录 Cloudflare → **Add a site** → 输入域名 → 选 Free 计划
- Cloudflare 会给出两个 **Nameserver 地址**，回到域名服务商把 DNS 服务器改成这两个地址
- 等待生效（通常几分钟，最长 24 小时），Cloudflare 面板显示 **Active** 即完成

## 一键配置（自动完成所有步骤）

```bash
cd D:\AICoding\English_Translate
npm run tunnel:fixed -- english.你的域名.com
```

脚本自动执行：
1. 构建生产版本 + 启动生产服务（3002 端口）
2. 登录 Cloudflare（**浏览器会弹出授权页，选择你的域名并点授权**）
3. 创建命名隧道（guodong-english）
4. 自动创建 DNS 记录把域名指向隧道
5. 写入配置文件（deploy/cloudflared-config.yml）
6. 启动隧道并打印固定地址

## 日常使用

```bash
npm run tunnel:fixed -- english.你的域名.com
```

保持窗口运行即可（Ctrl+C 停止）。命名隧道由 cloudflared 原生自动重连，地址永久不变。

## 开机自启（可选）

Windows 上可以用"任务计划程序"开机自启，或安装 NSSM 把 cloudflared 注册为服务：

```
nssm install GuodongTunnel "C:\路径\scripts\.cache\cloudflared.exe" "tunnel run --config D:\AICoding\English_Translate\deploy\cloudflared-config.yml guodong-english"
nssm start GuodongTunnel
```

（生产服务同样可以用 NSSM 注册为服务，详见 README 的 PM2 方案）

## 安全提醒

网站目前**没有登录功能**，任何人拿到网址都能访问你的学习数据。建议在 Cloudflare 面板：
- Access → Applications → 添加该域名 → 开启 Email OTP 登录（免费，用你的邮箱收验证码）
这样只有你能访问，比 Basic Auth 更简单。

## 常见问题

| 问题 | 解决 |
|---|---|
| 授权页没弹出 | 终端里会打印授权链接，手动复制到浏览器打开 |
| 域名状态不是 Active | 等 DNS 生效，或在 Cloudflare 面板重试 |
| 手机打不开 | 检查电脑没睡眠（`powercfg /change standby-timeout-ac 0`）、窗口还在运行 |
